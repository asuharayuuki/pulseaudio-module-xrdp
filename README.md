# pulseaudio-module-xrdp for Debian 13 arm64

Unofficial Debian packaging of [neutrinolabs/pulseaudio-module-xrdp](https://github.com/neutrinolabs/pulseaudio-module-xrdp), with a prebuilt `.deb` for Debian 13 (trixie) arm64.

The package contains compiled audio output and input modules. **No compilation is required when installing the prebuilt package.**

## Package information

| Component | Version |
| --- | --- |
| Target | Debian 13 (trixie), arm64 |
| Upstream modules | `v0.8` |
| Debian package | `0.8-1~deb13+local1` |
| Required PulseAudio | `17.0+dfsg1-2+b1` |
| Minimum xrdp | `0.9.8` |

## Download and install

Download the `.deb` and checksums from [Releases](https://github.com/asuharayuuki/pulseaudio-module-xrdp/releases), or use the package in [dist/](dist/).

```sh
sudo apt install ./pulseaudio-module-xrdp_0.8-1~deb13+local1_arm64.deb
```

APT resolves the runtime dependencies. The modules use PulseAudio's private module API, so this package requires the exact PulseAudio version listed above. A different PulseAudio version requires a matching build. These modules are for PulseAudio and cannot be loaded by `pipewire-pulse`.

## Package contents

- `module-xrdp-sink.so` and `module-xrdp-source.so` under `/usr/lib/pulse-17.0+dfsg1/modules/`.
- The upstream loader at `/usr/libexec/pulseaudio-module-xrdp/load_pa_modules.sh`.
- The upstream XDG autostart entry at `/etc/xdg/autostart/pulseaudio-xrdp.desktop`.
- License, upstream documentation, and build information under `/usr/share/doc/pulseaudio-module-xrdp/`.

## Runtime dependencies

```debcontrol
pulseaudio (= 17.0+dfsg1-2+b1),
pulseaudio-utils (= 17.0+dfsg1-2+b1),
xrdp (>= 0.9.8),
libc6 (>= 2.17)
```

The libc6 dependency is generated by `dpkg-shlibdeps`. Build tools are not runtime dependencies.
